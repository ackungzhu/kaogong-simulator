# 上岸模拟器 · 考公人生模拟游戏

> 30分钟体验一个考公人的一年。从报名到上岸/二战/转行，每个结局都是朋友圈素材。

## 🎮 玩法

- **7种身份开局**：985应届/选调生/三本二战/在职编外/海归/35+/宝妈
- **7个省份**：陕/粤/鲁/豫/苏/川/京，各有方言彩蛋
- **7个月份**：1-12月不同起点，决定卷度
- **数值系统v2**：精力/精神双轴+疲劳曲线+I/E人格社交修正
- **范进中举成就体系**：四阶段弧线（辱骂→发疯→掌嘴→前倨后恭）
- **80+随机事件**：赛博上坟/外耗/面霸诅咒/邪修路线…
- **9种结局**：上岸/二战/崩溃/考公转大专…

## 🚀 本地运行

```bash
cd 上岸模拟器_Demo
python -m http.server 8765
# 浏览器打开 http://localhost:8765
```
